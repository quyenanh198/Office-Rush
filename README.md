# Office Rush 3D — Coffee & Deadlines

Webgame 3D bằng **Three.js** dành cho dân văn phòng: lướt ghế xoay né Sếp, tránh máy in kẹt giấy, gom cà phê đá để kích hoạt **Flow State**, và có sẵn **Boss Key (`B`)** bật Excel giả trong 0.1 giây.

## Chạy nhanh
```bash
npm install
npm run dev
```

## Điều khiển
- `A` / `D` hoặc `⬅️` / `➡️` (hoặc vuốt ngang): Đổi làn
- `W` / `Space` / `⬆️` (hoặc vuốt lên): Nhảy
- `B`: **Boss Key** (mở bảng tính Excel giả & tắt tiếng ngay lập tức)
- `P` / `Esc`: Tạm dừng
- `M`: Tắt/bật âm thanh
